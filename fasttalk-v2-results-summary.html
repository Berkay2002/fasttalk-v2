Selected system

One bounded native pipeline.

Context correction
32K, parallel 1

llama.cpp divides context across parallel slots. The old 16K, parallel 4 profile gave one conversation about 4K tokens. A 12,034-token needle recall failed there and passed after moving to one true 32K slot.

STT tradeoff
1.69% WER

Parakeet was slower than the Nemotron control in raw streaming RTF, but reduced errors from 6.78% to 1.69% on the same six-fixture, 59-word regression corpus.

The corpus includes quiet speech, hesitation, acknowledgement, a long question, deterministic noise, and speaker playback with an AEC reference.

158 PCM reads

The client received many PCM chunks before the native clause finished. This establishes incremental transport rather than a buffered WAV returned at the end.

Cancellation boundary
26.12 ms

Playback and client delivery stop immediately on interruption. The bounded clause already inside the native speech worker drains so that the worker remains stable. Native compute within that clause is not claimed as cancelled.

Install lifecycle

Desktop app

Minimal controls around a visible local pipeline.

The interface uses the visual language of LiveKit Agents UI without LiveKit session behavior. It includes a Wave visualizer, realtime transcript, thinking state, model and license visibility, audio device selection, diagnostics, mute, stop, and interruption controls.

Release state

Packaged, with four limits stated plainly.

The final bundle is a 528,865,212-byte current-user NSIS installer. The locked release workspace tests, strict Clippy gate, frontend production build, Tauri bundle, sanitized install, launch, hash verification, and uninstall all passed.
